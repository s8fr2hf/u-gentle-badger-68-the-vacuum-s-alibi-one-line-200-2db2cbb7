A robot vacuum's deadpan one-line excuse for missing a spot — sensors,
a sock, a crumb, and something it has classified as evidence. Pure Python
3 standard library; `main.py` writes the alibi to `/output/entry.txt`.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
